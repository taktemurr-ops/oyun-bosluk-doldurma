# Eksik Harfler · Missing Letters

Boşlukları taşlarla doldur!

Kelimelerden bazı harfler silindi; eksik harfler alttaki tepside. Boş kareyi seç, sonra uygun taşa dokun. Bütün satırlar gerçek kelime olunca biter.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
